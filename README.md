# 🎞 3D Image Slider

A smooth and modern *3D Image Slider* built with *React, **TypeScript, **Tailwind CSS, and **Vite*.  
This project showcases animations and creative UI effects — all optimized for performance and simplicity.

---

## 🧠 Overview

This project is a *simple 3D image slider* that uses modern web technologies to display images with smooth transitions and perspective effects.  
It’s a lightweight, fast, and visually appealing component .

---

## 🚀 Features

- ⚛ *React + TypeScript* for robust and type-safe components  
- 💨 *Tailwind CSS* for styling and responsive design  
- 🎞 *3D Transform Animations* for a modern visual feel  
- ⚡ Built with *Vite* for ultra-fast development and build times  
- 🧩 Fully customizable and easy to integrate into any React project  

---

## 🧰 Tech Stack

| Technology | Purpose |
|-------------|----------|
| *React* | Frontend framework |
| *TypeScript* | Type safety and scalability |
| *Tailwind CSS* | Utility-first CSS framework |
| *Vite* | Development and build tool |
